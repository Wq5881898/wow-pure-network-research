# 高度差寻路专项知识记录

持续更新的纯网络专项。目的：记录高地、坡道、悬崖、多层地形的路径选择与服务端确认知识，避免仅凭平面距离或目标高度直线移动。

## 1. 证据层级

1. **观测**：新登录角色位置、目标服务器位置、地图、会话及时间。
2. **离线候选**：Detour完整走廊、投影误差、路径点及地形属性。
3. **移动提交**：已发送路径，不等于已走通。
4. **独立确认**：关闭会话后新登录位置核对；每段记录真实高度、HP、幽灵/战斗状态。
5. **持续验收**：最终到位、无跌落伤害或其他异常、独立重登，才记为本案例真实通过。

不把离线PASS、请求返回submittedPosition或缓存坐标当作服务端到位证明。

## 2. 坐标与投影要点

- WoW坐标(x,y,z)，z为高度；当前Detour工具映射为(y,z,x)，Detour第二轴为竖直方向。
- 当前端点搜索半径ext={5,12,5}，允许竖直搜索12码；这只是搜索窗口，不是允许跳高/下落12码。
- 当前工具要求findPath到达终点多边形，拒绝节点不足、buffer截断、部分路径。
- findStraightPath使用ALL_CROSSINGS；路径顶点再投影至附近detail表面。
- **局限**：顶点重新findNearestPoly可能选到相邻高度层；尚未逐段在原多边形走廊内密集验证地面高度。线性插值加密只增加点数，不能保证贴地。
- includeFlags=1|2的介质语义应对照本机导航枚举核实，不将它自动解释为纯陆地安全路线。

## 3. 路线选择规则（待实机验证的工作标准）

- 同时比较水平距离、净高差、累计升降、完整路径长度和绕行比。
- 终点应是同层可达的交互落点，而非把NPC高度强套到玩家XY位置。
- 高度层不明确或投影偏差过大时停止，不能扩大投影窗口直到“找到路”。
- 路径短段坡度很大时，区分网格边界噪声、台阶、悬崖及错误投影，不直接认定可跳跃。
- 分段执行只沿已验证走廊，不跨拐点简化直线；每段有明确提交终点、时间预算及退出条件。
- 首次实机段优先短距离与小高差；确认后再延长。当前32码截段是旧脚本预算策略，不是普适安全阈值。
- 不用传送、数据库改位置、跳崖或复活替代普通步行下坡验证。
