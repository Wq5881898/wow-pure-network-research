# 准备区外移与提前接敌战斗交接

用户纠正准备区过于靠近刷新点，要求往外移；计划目标提前接敌即可提前战斗。

efficiency新增hunt-stop-distance默认30码，在旧猎区终点外30码结束旅行。travel默认遇敌撤离保持，只有显式combat_handoff确认时交给战斗循环：本角色生命至少70%、非幽灵、服务端事件唯一指向本角色的存活目标、entry3125且6级、已有travel_return_route。多怪/错误entry或等级/低血不交接。

循环在已接敌时先确认同样的计划攻击者，直接复用预存退路调用既有_do_fight，不再先等待回血或做逐边反向规划。未接敌仍满血开新单元，仍不追逃跑目标，原低血控制不修改。新的主动选怪退路仍须预检。

travel与exit_recovery直接retreat后同步最后桥接submittedPosition到backend位置缓存，保持本地提交语义，不冒充服务端确认。

针对性travel11项、攻击者7项通过，包含默认撤离、显式交接、多怪/错级/低血拒绝与原死亡前缀。新增实机尚待验收；不以测试替代升级结果。用户授权子agent监督，第一次实现委托因继承父AGENTS隔离规则返回未执行，主agent在用户明确指定的独立子仓库内完成这些更改，未操作父客户端仓库。
