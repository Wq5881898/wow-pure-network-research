# 第一批复审与修正（2026-11-06）

## 结论

上批方向部分正确，但不能整体通过验收。DBC记录起点、字符串偏移与施法时间关联的修正有源码支持；统一未知状态处理的方向正确。新实现和报告仍有缺陷，本次先修复已定位部分，保留未闭合项，不进入实机。

## 本次修正

1. `OutOfCombatConfirmator.confirmed` 原只检查次数，漏掉驻留时间；现在属性与 `observe()` 使用相同的次数及时间判据。新增快速连续样本反例。重复/倒退/非有限时间不能确认，幽灵不能确认存活脱战。
2. `close_session` 原在恢复返回 `combat_cleared=False` 但末帧为False时仍可登出；现在失败确认阻止该分支登出。新增真实收尾入口反例。
3. 被动阶段末帧未知时，不允许继续进入攻击择优分支。撤离样本缺时间戳不再伪造时间累计确认。
4. `_supervise_until_safe` 原仍用 `is not True` 判断安全；改为只有明确False才进入非战斗分支。此修改尚不等于全监督链完成验收。
5. DBC读取器补充短头、非法字符串偏移、缺失NUL的拒绝；CastTime按有符号int32解析；缺少本机源码时不再在导入期间因未定义DbcError崩溃。格式串长度不匹配提前退出。数据库调用不再把口令放到命令行参数。
6. 抓包检查开始统计 `replay()` 返回的 `errors`，有解码错误时不再给出阴性结论。输出限定为捕获片段，不把归档文件数当独立会话数。

## 再后续：原进程持续持有监督（优先于上一段状态）

主运行器和旅行入口现在显式使用 `hold_ownership=True`。监督窗口到期不会返回并遗留无人接管的会话，而是在原进程开始下一恢复窗口；观察错误保留所有权，不强制关闭。保留最近20次尝试与总次数，避免长期监督无限积累尝试记录。主运行器用原子报告保存监督状态；旅行入口写独立 `.supervision.json`，最终结果仍独占创建。

确认窗口看到 `in_combat=True` 立即返回恢复路径，不再把剩余确认预算花在纯等待。新增3项反例覆盖窗口到期继续监督、观察异常后继续持有、安静确认途中重新接战恢复。WSL全量运行435项，全部通过；没有登录游戏。

观测新增 `transport_poll` 证据：轮询完成时间、前后cursor、新包数、是否追平队列。它能区分新轮询与缓存字段，但**不证明服务器重新下发战斗字段**。当前连续确认仍是对最近已知状态的重复检查，不是三次新服务器确认；尚未建立字段级新鲜度与连接失效的完整规则。

边界：这是原进程持续监督，不是跨进程守护或崩溃恢复；进程退出/系统故障/KeyboardInterrupt不保证所有权转移。RPC自身timeout仍独立于监督窗口。不得将本次离线通过写为无人值守实机通过。

## TCP读取错误与静默失联传播链核查

已实际读取WSL本机Agent-WOW源码：

- `pkg/worldconn/protocol.go:32–62`：ReadPacket中的io.ReadFull错误原样返回。
- `pkg/world/session.go:256–307`：reader把错误放入有界packets通道；engine返回后停止模块、取消context、关闭连接、记录err并关闭Done。
- `pkg/world/engine.go:167–174`：读取错误变为 `worldserver disconnected`；`:138–144` 的Pong超时也终止循环。默认timings为ping30秒、pong90秒、logout30秒、entry10秒。
- `cmd/char_play.go:150–163`：Done关闭后，servePlay取得Err并Shutdown RPC，等待在途响应最多5秒。此链说明已检测到的断线不会被设计为永久后台静默，但检测窗口与清理等待仍存在。
- JSON-RPC router仅有session.logout及模块分发；不能把不存在的session.status当作可调用接口。

运行底层现有离线测试（未修改上游checkout）：`go test ./pkg/world ./cmd -run 'TestMalformedPacketsAndDisconnect|TestExpiredPongDoesNotRenewLiveness|TestCloseJoinsSessionAndDoesNotConfirmLogout' -count=1`。world包通过；cmd包该筛选无匹配测试，不能报作CLI断线测试通过。这证明现有模拟对端的EOF传播、过期Pong拒绝续命及Close不冒充登出的测试通过，不是部署中的实机断网验收。

**剩余边界**：Pong有效性在底层会话已有实现，但桥接Poll未暴露最近有效Pong或会话Snapshot。检测窗口内，进程存活和RPC成功不能证明刚收到服务器回复；当前仅能拒绝已观察到的失败，不能承诺即时断线检测。下一步如需更强实时判据，应先定义只读连接证据契约，再为桥接增加有版本的只读状态字段并独立构建验证。禁止把本次源码核查写成实机断线恢复通过。
