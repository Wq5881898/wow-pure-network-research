# 知识库 · 索引

> **用法**：遇到问题先在这里搜，再动手。
> `python scripts/kb_lookup.py <关键词>`（例如 `leash`、`风筝`、`尸体`、`位置过期`）。
> 本目录是纯 markdown + wiki 链接（方括号双写的条目名），**可以直接用 Obsidian 打开本仓库根目录作为 vault**，
> 不必另建一份（另建会与仓库漂移，而仓库是版本化、可评审、有 CI 的那一份）。

| 层 | 内容 | 什么时候看 |

## 三条硬纪律

1. **动手前先读** `docs/kb/` 与相关 `docs/NN_*.md`（本轮吃过两次亏：漏读 docs/41/43/51、漏读 docs/72）。
2. **判据要独立于实现**：报告字段"看起来正常"不等于验证通过（esc008 教训）。
3. **反复失败先怀疑方向**：去 [[sources]] 的本机源码查判定，别再调参数。
