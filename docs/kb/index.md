# 知识库 · 索引

> **用法**：遇到问题先在这里搜，再动手。
> `python scripts/kb_lookup.py <关键词>`（例如 `leash`、`风筝`、`尸体`、`位置过期`）。
> 本目录是纯 markdown + `[[wiki 链接]]`，**可以直接用 Obsidian 打开本仓库根目录作为 vault**，
> 不必另建一份（另建会与仓库漂移，而仓库是版本化、可评审、有 CI 的那一份）。

## 三层

| 层 | 内容 | 什么时候看 |
|---|---|---|
| [[sources]] | 所有外部来源 + **本机镜像路径** + 取得状态（原文/镜像/摘要/未取得） | 要查上游时；网络不稳时优先看本机副本 |
| `mechanisms/` | **服务端机制的权威判定**（常量、函数、源码位置）+ 本机实测值 + 已实装位置 | "为什么会这样" —— **先查这里，别用命试** |
| [[教训-不要重做]] | 已否决的方案 + 原因 | 动手前；反复失败时 |

## 机制速查

| 机制 | 一句话 |
|---|---|
| [[机制-脱战-leash]] | 怪放弃的条件：**离它出生点 > 30 码** 且 **距最后一次伤害 ≥ 11 秒**；判定看**出生点**，不是它当前所在 |
| [[机制-尸体回收与跑尸]] | 回收半径 **39 码**（不必站到尸体上）；死后要**先释放灵魂**；尸体对象沿用角色 guid |
| [[机制-战斗契约与目标计数]] | 近战 ≤5 码才开战、逃跑目标不追（**项目方设计**）；计数按 **entry**；3101 会风筝 |

## 三条硬纪律

1. **动手前先读** `docs/kb/` 与相关 `docs/NN_*.md`（本轮吃过两次亏：漏读 docs/41/43/51、漏读 docs/72）。
2. **判据要独立于实现**：报告字段"看起来正常"不等于验证通过（esc008 教训）。
3. **反复失败先怀疑方向**：去 [[sources]] 的本机源码查判定，别再调参数。
