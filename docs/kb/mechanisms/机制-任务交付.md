## 两段式流程（服务端权威）

| 步骤 | opcode | 包内容 | 桥接动作 |
|---|---|---|---|
| 1 完成 | `CMSG_QUESTGIVER_COMPLETE_QUEST` = **0x18A** | `guid`(8) + `questId`(4) | `bridge.complete_quest` ✓ 已有 |
| 服务器回 | `SMSG_QUESTGIVER_OFFER_REWARD` = 0x18D | — | — |
| 2 选奖励 | `CMSG_QUESTGIVER_CHOOSE_REWARD` = **0x18E** | `guid`(8) + `questId`(4) + `rewardIndex`(4) | `bridge.reward_quest` ✓ 已有 |

出处：本机 AzerothCore `src/server/game/Handlers/QuestHandler.cpp`
（`HandleQuestgiverCompleteQuestOpcode` 读 `guid + questId`；
`HandleQuestgiverChooseRewardOpcode` 读 `guid + questId + reward`，
且 `reward >= QUEST_REWARD_CHOICES_COUNT` 会报"hacking attempt"）
与 `src/server/game/Server/Opcodes.h`。

**⇒ 桥接的 `quest.go` 两个动作都已实现，包格式与处理函数一致 ✓ —— 不需要改 Go。**

## ⚠️ queststarter ≠ questender（2026-11-01 实机踩到）

**给予者**（queststarter，`creature_queststarter`）和**交付人**（questender，
`creature_questender`）**可以是两个不同的 NPC** ⇒

| 任务 | queststarter（谁给你） | questender（交给谁） | 结果 |
|---|---|---|---|
| 794 | 3145 Zureetha Fargaze | **3145 Zureetha Fargaze** | ✅ 交付成功 |
| 805 | 3145 Zureetha Fargaze | **3188 Master Gadrin**（-825.6, -4920.8, 19.7，720 码外，在 Sen'jin Village） | ❌ 交给 3145 会**被服务器静默忽略** |

**⇒ 症状**：两张包（`CMSG_QUESTGIVER_COMPLETE_QUEST` 0x18A +
`CMSG_QUESTGIVER_CHOOSE_REWARD` 0x18E）都发了，**服务器一个应答都不回**
（包里没有 0x18D/0x18F/0x191）⇒ 任务留在任务栏里（`still_listed`）。

**⇒ 原因**（本机 `QuestHandler.cpp::HandleQuestgiverCompleteQuest`）：
```cpp
Object* object = ObjectAccessor::GetObjectByTypeMask(*_player, guid, TYPEMASK_UNIT | TYPEMASK_GAMEOBJECT);
if (!object || !object->hasInvolvedQuest(questId)) return;   // ← questender 不对就到这里结束
```
**⇒ 查交付人**：`select id,quest from acore_world.creature_questender where quest=<id>` ✓
（`creature_questender` 的列名是 `id`/`quest` ✓ —— 和 `creature_queststarter` 一样 ✓）

**⇒ 成功标志**：包里出现 **`SMSG_QUESTGIVER_QUEST_COMPLETE` = 0x191** ✓
（`SMSG_QUESTGIVER_REQUEST_ITEMS` = 0x18B 表示服务器要你交物品 ✓
—— 收集类任务会有这一步 ✓；`SMSG_QUESTGIVER_QUEST_INVALID` = 0x18F 表示无效 ✓）

**⇒ 交任务的正确做法**：先查 questender ⇒ 走到那个 NPC ⇒
`scripts/turn_in_quest.py --quest <id> --giver-entry <questender的entry>` ✓

## 物品收集任务（2026-11-01 quest 794）

**794「Burning Blade Medallion」**：收集 **1× item 4859**（不是击杀目标 ✓），
全服**只有 entry 3183「Yarrog Baneshadow」（5 级，98 HP）** 掉 ✓。

**⇒ 三条口径**：

| # | 事实 | 后果 |
|---|---|---|
| 1 | **物品目标的进度在背包里**（`item_totals`），**任务栏 counters 永远是 0** | 批次驱动器读任务栏 ⇒ 永远判"计数没涨" ✓ 已修为读背包 |
| 2 | **战斗的期望值不能要求"计数已涨"** | 物品要靠**后面**的 loot 动作才进包 ⇒ 先鸡先蛋 ✓ 已修 |
| 3 | **`if quest_id: 删掉 loot 动作`** 是击杀任务的旧语义 | 带 quest id 的**物品**任务因此永远拿不到物品 ✓ 已修 |

**⇒ 交付动作本身不需要 loot**（loot 属于战斗单元 ✓）；
`scripts/turn_in_quest.py` 只负责两步交付 ✓。
