## 敌对关系怎么判（权威来源：`FactionTemplate.dbc`）

服务端数据目录：`C:\Azerothcore\azerothcore-wotlk\build\bin\Debug\data\dbc\FactionTemplate.dbc`
（格式：WDBC，记录索引 = 阵营 ID；字段 0=ID、1=Flags、2=FactionGroup、3=FriendGroup、4=EnemyGroup）

`FactionTemplate::IsHostileTo(A, B)` 的判据：

```
hostile(A, B)  ⟺  A.group != B.group
                ∧ (A.friendGroup & B.group) == 0
                ∧ (A.enemyGroup  & B.group) != 0
```

对玩家（阵营组 2）算下来，**共有 122 个阵营是敌对的**（含 7、189、413 等）。

## 关键陷阱：**敌对 ≠ 会还手**

| 事实 | 后果 |
|---|---|
| **3101 Vile Familiar 的 faction 是 7（敌对），但它是 CritterAI 被动怪** | 挨打只会跑（`Flee For Assist`），**从不还手** ⇒ `in_combat` 全程 False ⇒ **撤离分支根本没机会执行** |
| **3124 Scorpid Worker（faction 7）** | 同样被动 |
| **3098 Mottled Boar（faction 189，敌对）** | 1–2 级，对 3 级角色是**灰怪** ⇒ 不主动攻击 |
| **10556 Lazy Peon（faction 29，Horde）** | 友方 ⇒ 不攻击 |
| 本机实测（b26/b27/b28/b31） | 上述怪全部"不还手"：角色 HP 恒 108、`in_combat` 恒 false、目标直接死掉或走开 |

**⇒ 结论：找测试对象必须同时满足三条**
1. faction 对玩家**敌对**（用上面的 DBC 判据算，别猜）；
2. **等级不低于角色**（等级更低的怪是灰怪，不主动攻击）；
3. **AI 不是被动**（CritterAI / 宠物 AI 的怪挨打就跑）。

**⇒ 本机 3101 刷新区（-253.6, -4316.1, 56）附近 120 码内一条都不满足**
（该区 faction 只有 7 / 189 / 29，见 `results/pure_network/agent_wow_huntobs_b29_*.json`）。
**最近的合格目标是 3125 Clattering Scorpid（faction 413，5–6 级）**，在 **373 码**外
（-103.1, -4657.6, 33.7），途中有一处 navmesh 断点。

## 对撤离实验的影响（重要）

撤离机制（见 [[机制-怪何时真正放弃-NO_PATH]]）的验证需要一个**真的在战斗中**的角色。
**用被动怪测不出来**：b26/b27/b28/b31 都是"目标不还手 ⇒ 从未进入战斗 ⇒
撤离分支没被触发"，`combat_cleared` 的 reason 是 `not_in_combat` 而不是撤离成功。

**⇒ 实机撤离实验的前置条件**：先走到有敌对怪的地方（当前是 3125），
用 `--low-health-ratio` 让战斗在接触后中止，再看 `in_combat` 是否由 True 转 False。
