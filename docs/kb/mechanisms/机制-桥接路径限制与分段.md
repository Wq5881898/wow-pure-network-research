# 机制 · 桥接路径限制与分段

> 桥接对路径有**硬校验**，违反就整条拒绝 —— 角色原地不动，正是"站在怪旁边挨打"的成因。

## 校验规则（`bridge/modules/bridge/actions.go`，`validatePath`）

| 约束 | 值 | 违反时的报错 |
|---|---|---|
| 点数 | **1..128** | `path requires 1..128 points` |
| **每段水平距离** | **≤ 15 码** | `segment exceeds 15 yards or 3-yard height change` |
| **每段高差** | **≤ 3 码** | 同上 |
| **整条路径总长** | **0.05..50 码** | `path length must be .05..50 yards` |

其它：
- 目标点必须非空、非 NaN/Inf。
- 校验用的是**桥接自己跟踪的位置**当起点 —— 不是你算的起点。
  这就是"第一段就超 15 码"报错的来源（路线起点与角色实际位置不符）。
- 桥接的移动速度：`run=True` → **7 码/秒**；`run=False` → **2.5 码/秒**。

## 实装

- `scripts/agent_wow_session._send_path()`：按 **≤30 码**分段（留余量），逐段发送。
- `scripts/agent_wow_escape_control._chunks()`：撤离路径按 **≤25 码 / ≤100 点**分段。
- `scripts/agent_wow_session._densify()`：路径细分到 **3 码/步、2 码/高差步**；
  并**拒绝落差 >5 码的路段**（`route drops more than 5 yards; refusing cliff path`）。

## 踩过的坑

| 坑 | 原因 |
|---|---|
| 路径被拒 → 角色不动 → 被打死 | 起点与角色实际位置不符（用了过期坐标），见 [[机制-位置与坐标的权威性]] |
| 撤离被拒（`retreat_movement_rejected`） | 撤离路线**按目标缓存**，战斗把角色挪走后缓存起点就过期了 → 修法：角色离路线起点 >8 码就重规划 |
| 完整路线被"落差超过 5 码"拒绝 | 去向本机 mmaps 算的路线跨了悬崖 → **分段规划**：每段都通过同样的校验，走完一段再重规划（`scripts/agent_wow_travel.py`） |
