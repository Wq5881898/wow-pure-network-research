# 受限撤离接口与Qwen失败分支验收

## 已实现的离线接口

`scripts/agent_wow_retreat.py`可读取六段已核验的非战斗撤离计划，并提供独立`execute`状态契约。执行前校验角色/地图/生命、路线长度、点数、连续性与起点位置证据；日志独占创建，stop和follow_path均先记录dispatch，超时或错误保留unknown，不重发、不攻击、不自动登出。

**关键限制：当前会话未获得自身移动的服务器位置回显；登录时缓存坐标不等于战斗中实时位置。**接口仅允许一段最多20码的提交，且要求`current_position_confirmed=True`，现有真实后端并不提供该战斗中证据，所以接口没有接入实机入口、不能被称为可用的战斗撤离器。六段连续执行不可由提交终点推断下一段实际起点。

主控在`test_agent_wow_retreat_controller.py`覆盖单段提交、缺位置证据拒绝、重复journal拒绝、错误回复保持unknown等，全部通过。更大路线仍在非战斗下曾逐段重登通过（docs/82），不是战斗环境的通过证明。
