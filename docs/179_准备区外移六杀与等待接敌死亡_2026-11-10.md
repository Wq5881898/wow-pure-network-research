# 准备区外移六杀与等待接敌死亡

用户要求外移准备区，提前接敌直接战斗。dc启用30码准备区，6级3125单目标过滤，1800秒窗口、9级停止；子agent只读监督，主agent随后核查并恢复。

## 实测

48腿到旧猎区目标外27.7码，正式进入刷怪循环。timed_initial为8级1046/5400、203HP。6次target_dead对应6个不同GUID，均entry3125/6级；XP依次1046→1107→1163→1219→1275→1331→1387，合计341。尚未升9级。

正式窗口1223.775秒（20分23.8秒）后停止，非完整1800秒窗口。期间fight_and_approach250.803秒、recovery_wait22.007秒、target_wait875.148秒、selection6.224秒。窗口毛效率约1003XP/h，仅本次样本，未计准备/死亡恢复，不能当完成升级时间。

setup1206.715秒，teardown98.004秒，总2528.495秒。报告minimum_health100只覆盖循环记录；退出恢复第二轮已37HP，随后retreat dead。最后current HP198是旧快照，不是最终存活。

status=stopped_for_reconciliation，life/combat state requires recovery。没有return成功报告；session_ending.closed_after=death_or_ghost，明确未正常logout。本轮没有触发旅行combat_handoff，故只能确认准备区外移和6次正常战斗有效，不能写提前接敌交接实机通过。

## 明确缺陷与待核

战斗选择时用短接近反向路线覆盖travel_return_route，恢复所选路线仅4.075码，这是已知“6码反向接近不能脱离仇恨”教训的重复。不应把短接近当最终安全退路。等待期间新接敌未被planned_attacker接受，具体攻击者/数量/事件新鲜度须离线回放核对；尚未查明前不猜根因或再开长实验。
