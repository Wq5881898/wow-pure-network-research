## 3. 经验二：目标供给必须允许刷新复用

**实机验证：**旧runner把成功和普通失败GUID都加入整个会话永久排除集合，运行越久可选目标越少。旧长会话30分钟击杀数为19、11、20、8、6、3、5、2，最后不足14分钟0杀。

修复为：
1. 普通接触失败、普通候选失效及已击杀目标的临时排除使用**180秒TTL**。
2. 明确危险的历史目标与临时失败分开存储，不因普通失败永久封禁。
3. TTL过期后**重新评估当前实际等级、健康、路径和邻怪**，不是无条件再次攻击。

真实记录已有同GUID普通失败约270秒后重新选中并成功击杀。TTL复用是已验证修复，不能再回退到普通GUID全会话永久排除。

**选怪原则：**在已核普通模板、可达区域内，优先有效非灰且不主动越级目标，不死守“必须等级减一”。15级时本区域11/12级基础奖励分别60/75；同级15级为120。放开有效目标解决了断供，但不代表11级永远是XP/h最优，需要比较完整周期。

## 4. 经验三：普通结果转移必须连续

以下转移已有实机证据，应该作为固定契约复用：

| 结果 | 正确处理 |
|---|---|
| 唯一选中目标主动接敌 | 正常近战接管，不因combat=true直接认定意外 |
| 普通候选失效、未进入危险战斗 | 临时排除、有界重选，不直接整链退出 |
| 目标死亡 | 优先记击杀，避免attack_stop先于HP0导致空攻击者误判多怪 |
| 击杀后非满血 | 共享恢复→满血及新鲜脱战确认→下一只 |
| 正常撤退成功 | 恢复满血后继续选怪；不等用户重复批准 |
| 额外攻击者、连接未知、死亡、退路失效 | 专门恢复，不伪装为普通无目标 |

**教训：**局部函数测试通过不等于最终runner正确。曾多次出现模板已改、字符串替换漏命中、实际worker仍执行旧断言。应测试最终展开入口和真实状态转移，避免继续堆叠exec字符串补丁。

## 5. 斩杀与退出：已验证什么、尚未验证什么

### 5.1 已发生的失败与已修复行为

[docs/229](229_16级运行49杀后38秒预算退出死亡与实际跑尸恢复_2026-11-18.md)：单体战斗38秒到期，角色102HP、怪21HP、怒气1000。旧timer出口没有施放1715，直接撤离后死亡。已真实跑尸并安全撤回，未用灵魂医者。

- 强制退出统一协调合法1715与移动，不能出现timer分支漏掉退出手段。
- 低血时不原地等待光环；正常后续drain被动确认晚到1715，不重发。

预算及正常接续回归通过，修复后继续完成了等级目标。**没有取得明确的“实机跨38秒后击杀”专项样本，不能把整轮成功替代该分支覆盖。**

- 位置使用桥接accepted submitted落点并保留来源，不冒充持续服务器位置回显。

## 8. 长会话、监督与性能经验

### 已实机验证
- 4096限制应针对单批suffix，而不是整个session累计。之前累计预算会使后续drain和恢复永久失败。
- 修复后已有真实4467包、28168包等长会话证据，正常恢复及后续击杀可用。
- 唯一owner、PID启动身份、会话/游标、冻结hash、fresh独立DBoffline/flags0及无CLI共同构成维护接续门。
- `last_xp_epoch`必须来自实际协议进展，不能用会话边界刷新；`last_progress_epoch`等字段名不一致会误停。
- 最终`finished_at`必须force保存，不能被普通写入节流吞掉。

### 禁止重复的误解
- 进程在后台运行 ≠ 模型正在持续监督。
- watchdog写alert文件 ≠ 主agent或用户已收到通知。
- owner残留CLI PID/current ≠ 进程仍在线或实时经验。
- 工具一次503 ≠ 连续数小时网络服务不可用。

### 性能优化待验证
- 账本采用父扣子互斥时间；unknown单列，RPC按method与parent记录。
- 通用sleep不能全叫respawn_wait，combat poll/回血/等目标/最终65秒应拆开。
- 完整报告反复序列化已出现约12分钟开销；可准备增量追加和有界快照，但需断电/异常恢复与最终完整落盘验证。
- 每30分钟维护是隔离累积风险的当前措施。未先验证长期状态、报告开销及告警可靠性前，不直接取消全部维护或安全收尾。
