# AzerothCore 纯网络路线证据目录

本目录属于纯网络协议路线；截图、系统登录、客户端输入路线留在 results 的其他位置。

- 根目录：纯网络运行产物。部分历史文件来自先前 VSS 恢复，存在此处不表示内容有效。
- archive_failed_stage2/：阶段二旧批次归档。
- recovery/vss11_2026-10-29/：保留来源的恢复副本，不作为新的成功实验。
- migration_*.json：迁移前源路径、目标路径、长度、SHA-256、全零标记与未迁移项。
- migration_*.journal.jsonl：逐文件迁移后校验记录。

历史 JSON 内路径保持原样，不修改原始证据。查询旧路径时参照迁移清单。
新运行日志、报告、trace 必须写入本目录。旧入口路径适配尚待完整验证，当前暂停真实批次。
